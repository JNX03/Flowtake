Flowtake covers the full workflow from recording to export in a single desktop app.

## Feature Areas

| Area | Description |
|------|-------------|
| [Recording](recording.md) | Screen capture, camera overlay, audio |
| [Editing](editing.md) | Timeline, zoom, pan, cursor animations, clips |
| [Effects & Overlays](effects.md) | Overlays, subtitles, masks, backgrounds |
| [Export](export.md) | FFmpeg encoding, formats, quality settings |

## Productivity Features

- **Teleprompter** — Built-in teleprompter with speech recognition sync
- **Presets** — Save and load recording/editing configurations
- **Asset Library** — Predefined assets for quick overlay creation
- **Project System** — Save, load, and manage editing projects
- **Hotkeys** — Fully customizable keyboard shortcuts
