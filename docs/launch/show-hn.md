# Show HN: maintainer preparation checklist

Status: not submitted. Reviewed October 1, 2026.

Hacker News requires people to write their own submissions and comments, and
prohibits generated or AI-edited text and automated posting. The previous
AI-prepared post has been removed. The maintainer should write the title and
explanation directly in their own words.

Read the current [HN guidelines](https://news.ycombinator.com/newsguidelines.html)
and [Show HN requirements](https://news.ycombinator.com/showhn.html) before
submitting.

## Facts to check while writing

- Link to the runnable project or official release, rather than only a landing
  page. Verify the installation path on the platform you describe.
- Explain your own reason for building Flowtake and one technical decision you
  can discuss from experience.
- State the exact published version, the separate FFmpeg requirement, and the
  Windows-primary/macOS-and-Linux-preview boundary.
- Keep recent source-only improvements separate from released download claims.
- Describe what ordinary workflows keep local and which explicit features use
  the network.
- If you include a demo, use the exact release and review the synthetic test
  recording and exported result before sharing it.

## Participation

Be present to answer technical questions personally. Do not ask friends or
other communities for upvotes, comments, or submissions. Do not automate replies,
delete and repost for visibility, or submit a minor release update as a new
Show HN. Use the feedback to improve the app and its installation instructions.
