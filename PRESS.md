# Flowtake Press Kit

## One-Liner

Flowtake is an open-source desktop screen recorder that automatically adds
polished zooms, pans, cursor motion, captions, masks, and export-ready edits.

## Short Description

Flowtake helps makers create polished product demos and tutorials locally. It
records screen, camera, mic, and system audio, then provides a built-in editor
with automatic zooms, smooth pans, cursor effects, captions, blur/redaction
masks, overlays, and FFmpeg export.

## Long Description

Flowtake is a free MIT-licensed desktop app for turning raw screen recordings
into polished videos. It combines Tauri v2, Rust, React, Pixi.js, and FFmpeg to
provide local recording, editing, rendering, and export in one workflow.

The project is built for open-source maintainers, indie hackers, developer
advocates, educators, and privacy-conscious teams that want Screen Studio-style
output without sending every recording through a hosted platform.

Windows is currently the primary stable platform. macOS and Linux builds are
available as developer previews while broader platform feedback is collected.

## Highlights

- Automatic zoom and pan animations from recording context.
- Built-in timeline editor for cuts, clips, captions, overlays, masks, and audio.
- Camera, microphone, and system audio recording.
- Local-first workflow with FFmpeg export.
- MIT licensed and open to contributions.
- Built with Tauri v2, Rust, React, Pixi.js, TailwindCSS, DaisyUI, and FFmpeg.
